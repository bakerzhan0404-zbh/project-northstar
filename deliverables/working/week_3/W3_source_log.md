## Governing evidence labels

| Label | Meaning | Permitted Week 3 use |
|---|---|---|
| `ACG-DATA` | Supplied client material or project dataset | State the supplied fact with scope, period, and source limitation |
| `ANALYST-CALC` | Reproducible calculation from supplied data | State the result with denominator, definition, and reproducible path |
| `ANALYST-ASSUMPTION` | Unverified scenario or input | Use for sensitivity or design only; never present as observed performance or benefit |
| `ANALYST-JUDGMENT` | Interpretation, score, threshold, or proposed action | Tie to evidence and counterevidence; require client approval where applicable |
| `JPM-PUBLIC` | Official public J.P. Morgan context | Use as contextual or hypothesis evidence only; never proof of ACG performance |
| `PUBLIC-CONTEXT` | Other public explanatory material | Use for terminology or design inspiration only; never substitute for ACG evidence |
