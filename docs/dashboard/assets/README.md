# Dashboard map asset

`world-map.png` is a locally vendored PNG rasterization of a CC0 Robinson-projection map. It is a decorative geographic reference for the Regional footprint disclosure. Analytical values and interactions are rendered as accessible HTML controls above the image; the image itself is not evidence and is hidden from assistive technology.

- Source: [Blank world map Robinson projection.svg on Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Blank_world_map_Robinson_projection.svg)
- Author: Justinkunimune
- Geography: 2022 de facto borders based on Natural Earth
- License: CC0 1.0 Universal Public Domain Dedication
- Retrieved: 2026-08-18
- Raster dimensions: 1,280 × 650 pixels
- SHA-256: `7097dc120bc4c45f15e1a116e2fd4b5b72dd84e45bec10063edd5fa5439e2154`

The dashboard uses only three governed business-region classifications—NA, EMEA, and APAC. Marker positions are deliberately schematic and must not be interpreted as bank, account, cash, legal-domicile, or transfer-path locations.
